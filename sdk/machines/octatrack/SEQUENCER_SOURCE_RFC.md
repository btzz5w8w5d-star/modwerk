# Sequencer source selection on the MKII development base

Candidate for the cumulative Octatrack base, derived from a9674ed84. The declaration and calling convention live in events.json. The Agent Board claim for octatrack/63-65 is linked to module draft #1997. The maintainer reviews the event numbers and proposed ABI 9 capability bit 0x4000 together before assignment.

The settings table runs in the UI task. Frame preparation runs after event staging and the deadline reports time remaining. A source switch there would miss events the stock scheduler already prepared. A take-site would transfer stock execution and register reconstruction to one module. The candidate instead uses the existing ordered, base-owned C dispatcher and its room check. No parallel clock, pattern copies, new transport or module-to-module references are needed.

At the scheduling boundary observers commit their own pending state. At the ordinary audio builder the sole selector receives the temporary pattern word, track and bank. The lower bank byte identifies the bank. A proposal outside 0–15, or a lane outside 0–7, falls back to the original signed pattern byte. The stock builder consumes the result. Both callbacks run in the sequencer task and preserve the C callee-saved registers and EMAC. The generated frame saves d0–d1/a0–a2. The source continuation installs the selected d3 and stack argument. A competing selector is refused by the loader's room check.

Modal input is an independent single-owner table. Early key/encoder delivery calls the active owner's ordinary handler with the tag 0x100. A zero return passes the control down the existing dispatcher. The base records consumed key downs through their release, including owner unload. An automatic missing-module notice waits for the owner to leave the modal page. Packages requiring the combined capability must supply the versioned marker, key, encoder, bank-load, boundary and selector entries. The metadata check runs before allocation and again on the relocated image. A feature absent from the base is rejected by the existing ABI 9 feature check.

A stopped OFF can leave a retired extent reachable in the unloading task's registers. Two later, bounded service attempts re-enter the existing stack/register reachability check on a fresh engine context. The collector still refuses to free a reachable extent. Cost on an instrument and coexistence in a full installed set remain open. The linked consumer and replay are developed separately in #1997.
